# Sprint_6
## Итоговый проект спринта № 6. 
Выполненные тесты проверяют избранную функциональность для ЯндексСамокат - приложения заказа самокатов. Были выполнены следующие проверки:
- Соответствие ответов вопросам на главной странице приложения.
- Переход на Дзен при клике на лого Яндекс в шапке приложения.
- Переход на главную страницу приложения при клике на лого Самокат в шапке приложения.
- Успешное оформление заказа при клике на кнопку Заказать в шапке приложения.
- Успешное оформление заказа при клике на кнопку Заказать в средней части главной страницы.
